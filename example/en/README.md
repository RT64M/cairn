# Northstar Ops

Northstar Ops is an internal operations ticket collaboration platform for support, fulfillment, finance, and operations leads.

It helps teams review customer requests, assign owners, add handling notes, track SLA risk, and preserve audit trails from one workspace.

## Current Scope

- Enterprise SSO and team-based permissions.
- Ticket list and detail workflows.
- Assignment, notes, status transitions, and bulk actions.
- Support-note audit review.
- SLA alerts and audit-log export.

## Open The Project

Run the frontend and API services for the target environment, then sign in with an authorized company SSO account.

## Limits

- No public registration.
- No customer self-service portal.
- No native mobile app.
- No cross-tenant ticket sharing.
