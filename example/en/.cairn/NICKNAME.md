# Glossary

| Term | Meaning |
| --- | --- |
| SLA | Service response or resolution deadline used to identify tickets approaching timeout |
| Queue | A ticket set formed by team, priority, status, and SLA-risk filters |
| Bulk assignment | A lead assigning multiple tickets to a team or owner in one action |
| Partial failure | A bulk-operation result where some items succeed and others fail |
| Retryable item | A failed item that can be submitted again after changing input or permission state |
| Audit note | A note flagged because of sensitive terms, refund content, escalation, or privacy content |
| Cross-team note | A handling note visible to multiple teams |
| Internal note | A handling note visible only within the current team |
| Operation audit | A record of actor, time, object, and context for sensitive operations |
| Pre-production | An environment close to production configuration for manual acceptance and external-system integration |

## Term Boundary

This file only explains stable business terms. Temporary task names, one-off testing notes, and review-batch issue descriptions do not belong here, so the glossary does not become TODO.
