# Northstar Ops

Northstar Ops 是一个面向内部运营团队的工单协作平台，服务于客服、履约、财务和运营主管。

它帮助团队在同一个工作台中查看客户请求、分派负责人、补充处理备注、跟踪 SLA 风险，并保留审计轨迹。

## 当前范围

- 企业 SSO 与团队权限。
- 工单列表与详情流程。
- 分派、备注、状态流转和批量操作。
- 客服备注审计。
- SLA 预警与审计日志导出。

## 打开项目

启动目标环境的前端和 API 服务后，使用有权限的企业 SSO 账号登录。

## 限制

- 不支持公开注册。
- 不提供客户自助门户。
- 不提供原生移动端。
- 不支持跨租户共享工单。
