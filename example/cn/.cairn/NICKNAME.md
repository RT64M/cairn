# 术语表

| 术语 | 说明 |
| --- | --- |
| SLA | 服务响应或解决时限，用于判断工单是否临近超时 |
| 队列 | 按团队、优先级、状态和 SLA 风险组合出的工单集合 |
| 批量分派 | 主管一次性把多条工单分派给团队或负责人 |
| 部分失败 | 批量操作中部分条目成功、部分条目失败的结果 |
| 可重试项 | 修改输入或权限后可以再次提交的失败条目 |
| 审计备注 | 因敏感词、退款、投诉升级或隐私内容被标记的备注 |
| 跨团队备注 | 对多个团队可见的处理说明 |
| 内部备注 | 仅当前团队内部可见的处理说明 |
| 操作审计 | 对敏感操作保存操作者、时间、对象和上下文 |
| 预发环境 | 接近生产配置、用于人工验收和外部系统联调的环境 |

## 约定词边界

本文件只解释稳定业务术语。临时任务名、一次性测试说明、某次 review 的问题描述不写入本文件，避免术语表变成 TODO。
