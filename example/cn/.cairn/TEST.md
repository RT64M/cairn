# 测试策略

## 测试分层

| 层级 | 目标 | 示例范围 |
| --- | --- | --- |
| 单元测试 | 验证状态机、权限判断、错误映射等纯逻辑 | 工单状态流转、错误码映射 |
| 契约测试 | 验证前后端 API 约定稳定 | 批量分派结果、备注错误结构 |
| 集成测试 | 验证数据库、API、队列协同 | 审计事件写入、通知任务入队 |
| 端到端测试 | 验证关键用户流程 | 登录后查看工单、批量分派、追加备注 |
| 人工验证 | 覆盖代理无法访问的真实外部环境 | 企业 SSO、真实通知、生产权限抽查 |

## 验收规则

- 涉及 API 结构变更时必须更新契约测试；
- 涉及权限变更时必须包含无权限场景；
- 涉及用户可见文案时必须检查 i18n key；
- 涉及外部账号、真实通知或预发环境时转入 `HUMAN.md`；
- 验证通过前不得把对应 TODO 标为 `[x]`。

## 人工测试边界

人工测试只处理代理无法完成的真实环境事项。能通过文档、静态检查、单元测试、契约测试或模拟环境完成的事项，不进入 `HUMAN.md`。
