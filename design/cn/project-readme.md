# README.md 设计

`README.md` 是面向用户的入口。它解释项目是什么、如何使用、如何配置，以及项目的边界和限制。

## 为什么需要

用户不应该为了使用项目去读代理协作规则、内部 TODO 或 review 记录。README 把用户视角和开发协作视角分开。

## 应写内容

- 项目目的。
- 安装、打开或运行流程。
- 常见使用方式。
- 配置说明。
- 隐私、限制和 FAQ。
- 用户可见的能力变更。

## 不写内容

- 代理读取顺序和状态约定，这些属于 `AGENTS.md`。
- 当前任务进度，这些属于 `TODO.md`。
- 设计大纲，这些属于 `plan.md`。
- 测试命令索引，这些属于 `TEST.md`。
- review 或 bug 反馈，这些属于 `fix_<desc>.md`。

## 与本仓库 README 的区别

本仓库根目录的 `README.md` 解释 Cairn 协议和顶层目录。下游项目的 `README.md` 应解释那个项目本身。
